# ChatGPT Sidebar Resizer — Retired

**Status:** RETIRED / DORMANT as of 2026-09-29  
**Last released version:** 1.0.2

ChatGPT now provides native browser-sidebar resizing. The custom Sidebar Resizer userscript is therefore no longer the normal implementation and should remain disabled in Tampermonkey.

The files in this directory are retained only as a fallback/reference baseline.

## Revisit only if

- ChatGPT removes or regresses native sidebar resizing; or
- the native sidebar handles long project/chat titles poorly enough that a narrowly scoped title-wrapping fix is worth restoring.

If only title wrapping is needed, prefer a title-only fix rather than re-enabling the retired resize logic.
